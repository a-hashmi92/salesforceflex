# Salesforce Flex website — updated logo version

## Add your logo
Place your `logo_transparent_background.png` file inside the `assets` folder. The header and footer both reference:
`assets/logo_transparent_background.png`

The logo image itself was not attached to this conversation, so it is intentionally not included in this archive. Add your own PNG at that exact path before publishing.

## Publish with GitHub Pages
1. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder to the root of your GitHub repository.
2. Add `logo_transparent_background.png` to `assets/`.
3. Open repository Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/(root)`, and save.
5. Test the GitHub Pages URL before pointing your custom domain away from Wix.
