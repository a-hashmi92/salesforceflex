# Salesforce Flex website

A responsive static website recreated from the public content on [salesforceflex.com](https://www.salesforceflex.com/) and restyled for a modern, lightweight experience.

## Files

- `index.html` — page content and sections
- `styles.css` — layout, colours, typography and responsive styles
- `script.js` — mobile navigation, current year and email-based contact form
- `assets/favicon.svg` — simple text-based favicon

## Preview locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `salesforceflex-website`.
2. Upload all files and folders in this project. Keep `index.html` at the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The repository's Pages settings will show the published URL.

## Use your existing domain

You can connect `salesforceflex.com` to GitHub Pages through **Settings → Pages → Custom domain** and the DNS records requested by GitHub. Do not change DNS until you are ready to switch the live website away from Wix. Keep the Wix site available until the GitHub Pages version and domain have been tested.

## Important notes

- This is a static site; it does not require a server or framework.
- The contact form opens the visitor's default email application with a prefilled email to `hello@salesforceflex.com`. It does not store or submit form data on a server.
- Project cards summarise the project themes listed on the existing website; they are not claims of measured client results.
- The new design is a recreation, not a pixel-perfect copy of Wix. Wix-specific animations, form integrations, blog post pages, analytics and other embedded features are not automatically migrated.
- Before launch, verify the wording, contact email, social profile URLs, images and any claims about services/certifications.
